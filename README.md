# Screenshot Tool releases

Installer and updates for Screenshot Tool, a personal Windows screenshot tool. This repo holds releases only; the source is private.

## Install

1. Download `ScreenshotTool-win-Setup.exe` from the [latest release](https://github.com/dracan/screenshot-tool-releases/releases/latest).
2. Run it. The installer isn't signed, so Windows SmartScreen may warn: choose **More info**, then **Run anyway**. If the warning only offers **Don't run**, right-click the downloaded file, choose **Properties**, tick **Unblock**, click **OK**, and run it again.

It installs for the current user (no admin rights needed), starts, and starts with Windows from then on. It checks for updates every few hours and installs them when it next quits; the tray menu also has **Check for updates**.

To uninstall: Settings > Apps > Installed apps > Screenshot Tool.
